# SemanticMemory v0.1.1

SemanticMemory is now packaged as `semantic-memory-reme`, a community companion
for ReMe.

## Highlights

- Renamed the PyPI distribution to avoid the existing `semantic-memory` package.
- Renamed the Python import namespace to `semantic_memory_reme`.
- Added `semantic-memory demo`, a temporary end-to-end demonstration.
- Added PyPI Trusted Publishing and release documentation.
- Clarified that the project is independent and not an official ReMe package.

## Install

```bash
python -m pip install semantic-memory-reme
semantic-memory demo
```

## Compatibility

- Python 3.11+
- Existing `semantic-memory/v1` claim schema
- Existing `semantic-memory-task/v1` task schema
- Existing `semantic-memory` and `semantic-memory-mcp` CLI names
