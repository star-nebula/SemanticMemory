# Code of Conduct

## Our Standard

This project welcomes practical, respectful collaboration. Participants should:

- discuss ideas and code without personal attacks;
- give actionable technical feedback;
- respect privacy and never post another person's memory, credentials, or data;
- assume good faith while asking for evidence when claims are disputed.

Harassment, discrimination, doxxing, credential disclosure, and deliberate privacy
violations are not acceptable.

## Scope

This standard applies in repository discussions, issues, pull requests, reviews,
and other project spaces.

## Enforcement

Maintainers may edit or remove contributions that violate this standard and may
temporarily or permanently restrict participation. Report sensitive conduct issues
through the repository's private maintainer channel rather than a public issue.
